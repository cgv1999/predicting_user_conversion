# MIPT 2025: Прогнозирование конверсии пользователя в первую подписку из пробного периода

## 🎯 **Контекст и бизнес-задача**

**Компания:** Онлайн-кинотеатр, предоставляющий доступ к библиотеке фильмов, сериалов и собственного контента по модели ежемесячной подписки.

**Продукт:** Мобильное и веб-приложение, где пользователи оформляют подписку и получают доступ к контенту.

**Бизнес-проблема:** Не все пользователи покупают подписку после окончания пробного периода. Это приводит к росту расходов на привлечение новых пользователей.

**Цель проекта:** В рамках маркетингово-аналитической платформы компании провести анализ данных, выявить инсайты и подготовить рекомендации для повышения удержания пользователей и снижения оттока.

## 📊 **Данные и описание колонок**

Датасет содержит информацию о конверсии пользователей из триального периода в покупку первой подписки:

- `user_id` — уникальный идентификатор пользователя
- `start_trial_date` — день начала триального периода пользователя
- `source` — источник появления пользователя на сервисе
- `device` — устройство, с которого пользователь зарегистрировался
- `city` — город, из которого пользователь зарегистрировался
- `favourite_genre` — любимый жанр, указанный пользователем при регистрации
- `avg_min_watch_daily` — среднее число минут просмотра в день
- `number_of_days_logged` — количество дней в течение триального периода, когда пользователь логировался на сервисе
- `churn` — купил ли пользователь подписку по окончании триального периода (1 - **НЕ купил**, 0 - **купил**)

## 🔍 **Ключевые результаты анализа**

### **📈 Общая статистика**
- **Всего пользователей:** 27,977
- **Купили подписку:** 22,077 (79%)
- **Не купили подписку:** 5,900 (21%)
- **Общая конверсия:** 79%

### **✅ Гипотеза 1 — ПОДТВЕРЖДЕНА**
**"Пользователи, которые больше времени проводят в приложении, с меньшей вероятностью купят подписку"**
- **Статистический тест:** U-тест Манна-Уитни
- **Результат:** p-value ≈ 0 (крайне значимо)
- **Вывод:** Существует статистически значимая обратная зависимость между временем просмотра и конверсией

### **❌ Гипотеза 2 — ОТВЕРГНУТА**
**"Пользователи, у которых iOS, с большей вероятностью купят подписку"**
- **Статистический тест:** Хи-квадрат тест
- **Результат:** p-value = 0.659 (незначимо)
- **Конверсия по устройствам:**
  - SmartTV: 79.6%
  - iOS: 79.2%
  - Web: 78.8%
  - Android: 78.6%
- **Вывод:** Тип устройства не влияет на вероятность покупки подписки

### **✅ Гипотеза 3 — ПОДТВЕРЖДЕНА**
**"Любимый жанр не влияет на то, купит человек подписку или нет"**
- **Статистический тест:** Хи-квадрат тест
- **Результат:** p-value = 0.759 (незначимо)
- **Конверсия по жанрам:**
  - Action: 79.6%
  - Criminal: 79.1%
  - Drama: 78.9%
  - Comedy: 78.8%
  - Thriller: 78.4%
- **Вывод:** Жанровые предпочтения не влияют на вероятность конверсии

## 🎯 **Аналитические выводы для ML-отдела**

### **🔴 Признаки для включения в модель:**
1. **`avg_min_watch_daily`** — **ключевой предиктор с обратной зависимостью**
   - Чем выше значение → тем ниже вероятность покупки
   - Сильная статистическая значимость (p ≈ 0)

### **🟡 Признаки для исключения или перепроверки:**
1. **`device`** — не показал статистической значимости
2. **`favourite_genre`** — не показал статистической значимости
3. Рекомендуется проверить в комбинации с другими признаками

### **🟢 Дополнительные рекомендации:**
1. **Дисбаланс классов:** 79% vs 21% — использовать F1-score, Precision-Recall, SMOTE
2. **Временные паттерны:** Исследовать `start_trial_date` на наличие сезонности
3. **География:** Проверить влияние города (`city`) на конверсию
4. **Источники трафика:** Проанализировать `source` на качество пользователей
